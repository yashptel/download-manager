# Chrome Web Store listing

OpenDM Connect's listing, item ID `mjebgoilgooegcpfbmjnapamjpcnhcbg`.

- `store-icon-128.png`: the store icon (the app tile, 96 px art with a shadow).
- `1-…5-*.png`: screenshots, 1280x800, 24-bit PNG.
- `promo-small.png` (440x280) and `promo-marquee.png` (1400x560).
- `compose.py`: renders the screenshots and tiles from captures of the app
  (taken with `OPENDM_DATA_DIR` pointing at a demo data folder) using
  headless Chrome. The video frame is from Sintel, Blender Foundation,
  CC BY 3.0.

The listing text and the privacy answers live in the dashboard. The privacy
policy is [docs/privacy.md](../../docs/privacy.md).
